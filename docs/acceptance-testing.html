1. What is Predict Structure?

In one sentence: A web app that lets scientists submit a protein, DNA, or RNA sequence and get back a predicted 3D structure — computed by one of four state-of-the-art AI models — plus a full quality report and interactive analysis tools.

System architecture

User Browser (React SPA) │ ▼ Predict Structure UI (this app) ──▶ GoWe workflow engine │ │ │ ▼ │ Tool containers: │ ├─ Boltz-2 │ ├─ Chai-1 │ ├─ AlphaFold 2 │ └─ ESMFold ▼ BV-BRC Workspace (inputs + outputs)

Key terms (primer for QA testers)

  • MSA — Multiple Sequence Alignment. A file of related sequences that gives evolutionary hints. Boltz/Chai need one. AF2 builds its own. ESMFold doesn't need one.
  • pLDDT — Per-residue confidence (0–100). >90 very high, 70–90 confident, 50–70 low, <50 very low.
  • pTM / ipTM — Overall structure confidence (0–1). >0.8 trustworthy; <0.5 probably wrong.
  • PAE — Predicted Aligned Error, in Å. Position error between every pair of residues.
Two ways to use the app. Standard mode is a guided 4-step wizard with auto tool selection (default for most users). Expert mode exposes per-tool workflows with every parameter. Toggle in the Settings dropdown (gear icon, top-right).

2. Before You Start

Test-data size guide. < 100 residues → fast (<5 min). 100–300 → medium (5–30 min). 300+ → could be an hour depending on the tool.

16. Brainstorming — Integration & Bigger Picture

Starting point for a design conversation with stakeholders. Testers should evaluate whether each integration would smooth their real-world workflows.

BV-BRC Data Flow Integration

Genome → Fold

  • "Fold this protein" button on any protein feature in BV-BRC genome browser
  • Auto-populated sequence — no copy/paste round-trip
  • Feature enrichment — predicted structures back-link into BV-BRC protein records

Proteome batch

  • "Fold selected proteins" from a genome's proteome page
  • Bulk submission — N jobs with sensible per-tool defaults
  • Progress dashboard for the batch

Comparative genomics

  • Fold ortholog groups across strains
  • Auto-populate Compare tab with structures from related organisms
  • Cross-species divergence mapping

Priority target lists

  • AMR gene structures — one-click fold of resistance factors
  • Virulence factors — auto-fold from pathogen genomes
  • Feed into vaccine / drug design pipelines

Cross-Tool Workflows

Predict → Annotate

  • Foldseek search — find similar structures in local library
  • Auto-populate Compare tab with structural neighbors
  • InterPro / Pfam overlay on pLDDT chart and 3D viewer

Predict → Dock

  • Docking-ready outputs for AutoDock / Vina
  • "Dock this" button hands off structure + ligand
  • Binding pocket detection as pre-step

Multi-tool ensemble

  • Run all four tools on same sequence
  • Consensus Compare view — agreement/disagreement
  • Confidence-weighted consensus structure

Iterative refinement

  • Divergent regions → sample more models in low-confidence areas
  • Reference-guided prediction using experimental PDB as template
  • Complex assembly pipeline — subunits → complex

External Ecosystem Integration

AlphaFold DB & PDB

  • Pre-flight AF DB lookup — save compute if already predicted
  • PDB cross-reference — offer close matches as starting reference
  • UniProt accession input — auto-fetch sequence and annotations

Downstream tools

  • ChimeraX / PyMOL export with confidence coloring baked in
  • ModelArchive submission — publish to community DB
  • Foldseek search — find similar structures by geometry

Documentation & citation

  • Methods paragraph auto-generator — tool version, DB version, parameters
  • Reproducibility ledger — container digest, DB snapshot
  • Provenance chain from BV-BRC feature to final structure

Sharing & collaboration

  • Public URL for a completed job (no BV-BRC account needed to view)
  • Version tree when user re-runs with different params
  • In-app feedback button to flag bad predictions

Anything else? — From a testing perspective

Trust & warnings

  • Prominent warnings when pLDDT is low or PAE suggests unreliability
  • Confidence bands everywhere — no false certainty
  • "Compare against reference" before publishing

Accessibility

  • Screen reader support
  • Keyboard navigation throughout
  • WCAG 2.1 AA compliance audit

Automation

  • Bulk submission from CSV/FASTA
  • API-first — documented endpoints for scripting
  • Notification hooks — email / Slack / webhook when done

Quotas & governance

  • Cost / compute dashboard per user
  • Scheduled re-runs with newer tool versions
  • Data retention policies — how long do outputs live?
